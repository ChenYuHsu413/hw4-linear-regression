## 2. 疑難排解與調優歷程 (基於 [log.md](file:///d:/AI%20Class%20ChenYu/AIClass/hw4/docs/log.md))

在開發與驗證的過程中，我們解決了以下關鍵技術問題：

* **套件依賴補齊**:
  - 偵測到執行環境缺少繪圖與機器學習套件，執行 `pip install numpy pandas matplotlib scikit-learn` 完成環境配置。
* **Windows 終端機編碼衝突 (UnicodeEncodeError)**:
  - 在傳統中文 Windows 預設編碼（`CP950`）終端機下執行時，`R²`（上標平方符號）導致系統崩潰。
  - **解決方案**: 將所有輸出的 `R²` 替換為英文標準字串 `R-squared`。
* **Scikit-Learn 特徵名稱警告 (UserWarning)**:
  - 由於模型是在 pandas DataFrame 上進行擬合，但預測線使用無特徵名稱的 NumPy 矩陣傳入，觸發了警告。
  - **解決方案**: 將 `model.predict()` 的輸入改為帶有特徵名稱的 `pd.DataFrame({'x': x_sorted})`。
* **Markdown 語法反斜線轉義警告 (SyntaxWarning)**:
  - Streamlit 載入 LaTeX 數學公式中（`\hat` 和 `\cdot`）的轉義字元引起編譯警告。
  - **解決方案**: 將 Markdown 文字區塊均宣告為原始字串（Raw strings），即在引號前加上 `r`。
* **參數限制放寬**:
  - 用戶嘗試將雜訊變異數 `var` 設定為 `500` 和 `100000`，觸發了原先設下的 `0-300` 驗證限制。
  - **解決方案**: 修改代碼限制至 `100000`，並修正對應的 ValueError 警告訊息，使邏輯與提示一致。
